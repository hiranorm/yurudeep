# souten

> 思考を、撃ち溜める。

会議中・授業中・読書中に「あ、これ後で調べたい」が連発します。
そのたびに今すぐ検索すると、本来集中したい場から脱線します。

souten は、その「調べたい欲」を**一時的にチャージ**して、後でまとめて
複数の検索エンジン / AI に**一斉発射**するための、ごく単機能な Web アプリです。

名前の由来は「**装填**（そうてん）」。思考の弾丸を装填して、後で撃ち放つ、というイメージそのまま。

- UI 最小
- 広告なし
- ログインなし
- サーバなし
- 離脱で揮発（永続化なし）

## 思想 — 「調べたい欲」を否定せず延期する

「気になったら即検索」も、「気にしないで我慢する」も、どちらも続きません。
souten は第三の選択肢として、**好奇心バッファ**を提供します。

- 集中したい場では、装填するだけ
- 区切りが来たら、ボタン一発で全部に火を着ける
- 発射後はクエリも履歴もきれいに消える

Todo リストではなく、「**今は読まないが、後で必ず一気に開く**」ための発射台です。

## 使い方

1. **装填** — 1 行入力欄に気になったキーワードを入れて Enter
2. **発射先を選ぶ** — Google はデフォルト ON、必要に応じて Perplexity / GitHub / Stack Overflow / Zenn / arXiv / Wikipedia などをチェック
3. **発射** — ボタンを押すと、クエリ × 発射先の組み合わせが新規タブで一斉に展開される

発射後は入力もチェックも初期状態に戻ります。
連続装填 → 連続発射、いくらでも繰り返せます。

## 発射先について

全 19 種類のエンジンを内蔵しています。

- 検索: Google / DuckDuckGo / Bing / Brave
- AI: Perplexity
- 動画: YouTube
- SNS: X / Reddit
- 技術（国際）: GitHub / Stack Overflow / npm / MDN
- 技術（日本語）: Zenn / Qiita
- ナレッジ: Wikipedia (JA)
- 学術: Google Scholar / arXiv / Hugging Face Papers
- このブログ: yurudeep

「あの 1 ワードを、Google も Perplexity も GitHub も全部で見たい」が 1 クリックで叶います。

## ちなみに

- クライアント完結で動きます。サーバには何も送りません
- LocalStorage も使わないので、ページを閉じればチェック状態もクエリも消えます
- 「履歴を残さない・残さなくていい」のが思想なので、ログイン機能は永久に付けません

## 広告代わりについて（フェアに書いておく）

souten はアプリ内に通常の広告を出していません。代わりに、**「ゆるディープ」という弾丸が初回起動時と発射 5 回ごとに自動装填**されます。発射時にチェック中の検索エンジン群と一緒に `yurudeep.com/?q={クエリ}` が新規タブで開きます。

ユーザーが souten を使うほど、ときどきこのブログが開かれる。それがこのアプリにとっての回遊経路で、ブログを置いておけるコストを支える仕組みです。

そのため、**ツール本体（souten.hira-euclid-norm-root2.workers.dev）を直接ブクマしてもらって構いません。** この入り口ページを経由しなくても、こちら都合の導線は最初からアプリの中に組み込んであります。
