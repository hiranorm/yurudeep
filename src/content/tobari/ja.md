# tobari

> 視界に、帳を下ろす。

作業や GPU 処理を回しているあいだ、PC は動かしたまま視界だけを遮断したい。
そのための、超軽量な Web アプリ群です。

- UI なし
- 広告なし
- ログインなし
- 設定なし
- 開いた瞬間に開始

## このページの使い方

このページをブックマークして、その日の気分でどの帳を下ろすか選ぶ運用を想定しています。

各アプリのリンクを直接ブクマしてもよいのですが、こちらとしてはまずここを経由してもらえると嬉しいです。今後、帳の種類を増やしていく予定があるので、その入り口としても機能します。
すぐ透けるような欺瞞は嫌いなので、こちらの都合も率直に書いておきます。

## 思想 — 触らせない

一般的な Web サービスは、回遊・通知・滞在延長を狙います。
tobari はその真逆です。

- 視界を遮断する
- 情報を遮断する
- 開いた瞬間から沈黙する
- 離脱は歓迎する

## 帳の選び方

下のボタンから、好きな帳を選んで開いてください。
タブを閉じれば、それで終わりです。

- **永遠の帳** — 開いた瞬間に暗転、ずっと暗いまま。Colab 放置・長時間処理向け。
- **深海の帳** — 深い藍に泡が昇る。完全な黒ではない、わずかなゆらぎ付き。
- **幕開けの帳** — 1 時間でゆるく明けて沈む、ポモドーロ代替。執筆・集中作業向け。

## ちなみに

- 画面スリープは [Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API) で抑止しています。タブがアクティブな間は、画面が落ちません。
- ただし OS のシステムスリープとは別軸です。OS スリープが厳しめの設定になっていると、画面が起きていても本体は落ちる場合があります。
