# tobari

> ปล่อยม่านปิดบังสายตา

ชุดเว็บแอปขนาดเล็กมาก ที่ทำให้หน้าจอมืดลงในขณะที่พีซียังคงทำงานต่อ
เปิดแล้วเริ่มทันที ปิดแท็บก็จบ

ไม่มี UI ไม่มีโฆษณา ไม่มีล็อกอิน ไม่มีการตั้งค่า

เพิ่มไตรภาคฤดูร้อนแล้ว: หิ่งห้อย / ดอกไม้ไฟ / ระลอกคลื่น

เลือกม่านที่ต้องการด้านล่าง
