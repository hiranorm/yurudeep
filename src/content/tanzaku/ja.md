# tanzaku

> 日本語を、縦に読もう。

日本語の小説や Web 記事を、本のように縦書きで読むためのブラウザアプリです。
青空文庫・小説家になろう・カクヨムなど、横書きで表示される日本語サイトを、縦組みに自動変換して読み下せます。

Android（Google Play）で配信中です。

## なぜ作ったか — 横書きで失われる読書体験

日本語の小説や古典は、もともと縦書きで組まれた文章です。
それをブラウザの横書きレイアウトで読むと、行の流れも改ページの呼吸も変わってしまい、本で読むときの没入感がそがれます。

tanzaku は WebView で開いたページに縦書き CSS を自動注入することで、サイト側を変更せずに、横書きのページをそのまま縦組みで表示します。読む体験だけを、本のかたちに戻すアプリです。

## できること

- **縦書き CSS 自動注入** — 横書きで提供されているページも自然な縦組みで読める
- **ホームから 1 タップ** — 縦書きで読みやすいサイトが並ぶアプリ内ホーム。タブを行き来する手間がない
- **しおり保存** — 和の伝統色で色分けされた、ひと目で分かるブックマーク
- **文字サイズ調整** — 長編をじっくり読むときも目に優しい大きさに
- **ページ位置の引き継ぎ** — リンク遷移後も本文位置がずれにくい
- **自動ページ送り（プレミアム）** — 読書中に画面が自動でスクロール。速度を細かく調整できる

## ホームに並ぶサイト

- **小説** — 青空文庫 / 小説家になろう / カクヨム / ハーメルン / アルファポリス
- **短歌** — Utakata
- **ブログ・読み物** — はてなブログ / note

※ 各サイトのコンテンツは各サイトの提供物であり、本アプリは縦組み表示を提供する閲覧用ブラウザです。

## 広告とプレミアムについて

無料で利用できます。アプリ内に控えめなバナー広告が表示されます。リワード動画を見ると、その日のうちは広告が非表示になります。
プレミアムに登録すると、広告の完全非表示と自動ページ送りが使えます。
